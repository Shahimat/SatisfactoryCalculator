# Проверить визуальные изменения: эталон и сравнение скриншотов

## Когда использовать
После рефакторинга или правки интерфейса, которые не должны менять вид экранов.

## Шаги
1. Собрать эталон до правки: `PAGES_BASE=/ npm run build` → проверка: появился каталог `dist/`.
2. Снять скриншоты эталона: `npm run visual:shots -- dist /tmp/visual/baseline` → проверка: в `/tmp/visual/baseline` по одному PNG на экран и `report.json`, код выхода 0.
3. Внести правку и собрать снова: `PAGES_BASE=/ npm run build` → проверка: `dist/` пересобран.
4. Снять скриншоты после правки: `npm run visual:shots -- dist /tmp/visual/current` → проверка: код выхода 0.
5. Сравнить: `npm run visual:compare -- /tmp/visual/baseline /tmp/visual/current /tmp/visual/diff` → проверка: по каждому экрану написано 0 px, код выхода 0. Различия — красным в PNG из `/tmp/visual/diff`.
6. Русская и английская версии снимаются отдельно: `LOCALE=en` перед командой шага 2 и шага 4, сравнивать только одну локаль с такой же локалью. Сравнение RU с EN даёт различия и код выхода 1.

## Если что-то пошло не так
- Скриншоты пустые или без стилей → сборка не для корня: нет `PAGES_BASE=/`, см. `publish-pages` шаг 2.
- `visual:shots` падает на поиске браузера → задать `CHROME=<путь к Chrome>` (по умолчанию `google-chrome-stable`).
- `visual:shots` завершается с кодом 1 → ошибка в консоли браузера или ввод в поле не обновил состояние на каждом символе; исправить в коде, не снимать эталон заново.
- Порт занят → задать `PORT=<номер>` (по умолчанию 4791).
- `visual:compare` не запускается → нужен ImageMagick (команда `compare`).
